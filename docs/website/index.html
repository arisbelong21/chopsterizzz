Chopster

Desktop content publishing tool for creators — runs locally on your own computer.

What it is

Chopster is a desktop application that helps a creator prepare their own video content — clipping, captioning and formatting — and publish that content to the creator's own social media accounts, including TikTok.

Chopster runs entirely on the user's own computer. It is not a web service, it does not operate a server, and it does not store user data in the cloud.

How it works

  • The user installs and runs Chopster locally on their own device.
  • The user signs in to TikTok and authorises Chopster to publish content to their own account.
  • The user selects a video file from their own device and confirms the caption.
  • Chopster sends that video to TikTok using the official TikTok Content Posting API, either as a draft in the creator's TikTok inbox for manual review, or as a direct post, depending on the authorisation the creator grants.

Data

  • Chopster stores the TikTok access token locally on the user's device only.
  • No content, token or personal data is transmitted to any server operated by Chopster, because Chopster operates no server.
  • Tokens are deleted immediately when the user disconnects their account.
